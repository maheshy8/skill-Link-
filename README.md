# Skill Link AI

AI-powered resume analysis and job recommendation platform.

## Features

- Resume parsing
- Skill extraction
- Job description analysis
- Resume-to-job matching
- Match score
- Skill-gap analysis
- Job recommendations
- Authentication-ready backend

## Tech Stack

Python • FastAPI • Scikit-learn • MongoDB • React.js • Git • Docker

## Project Structure

```text
skill-link-ai/
├── backend/
├── frontend/
├── data/
├── notebooks/
├── screenshots/
└── docs/
```

## Run Backend

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r backend/requirements.txt
```

Start API:

```bash
uvicorn backend.app.main:app --reload
```

Open:

```text
http://127.0.0.1:8000/docs
```
